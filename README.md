# FIRPA - Framework Inteligente de RPA para Administração Pública

## 📋 Sobre o Projeto

FIRPA é uma plataforma de avaliação de maturidade digital desenvolvida para auxiliar organizações públicas na implementação de Automação Robótica de Processos (RPA). Baseada em pesquisa científica apresentada no EnANPAD 2025, oferece ferramentas práticas para avaliar a prontidão organizacional e priorizar processos para automação.

**Autor:** Alexandre Calaes - Mestrado Profissional em Administração - UDESC/ESAG

## 🚀 Funcionalidades

- **Calculadora de Maturidade Digital**: Avaliação em 4 dimensões críticas
  - Maturidade de Processos
  - Infraestrutura Tecnológica
  - Capacitação da Equipe
  - Governança Digital

- **Ferramenta AHP**: Priorização científica de processos usando Análise Hierárquica
  - Comparação pareada de critérios
  - Avaliação multicritério de processos
  - Ranking automatizado de prioridades

- **Framework FIRPA**: Metodologia tridimensional validada cientificamente
  - Governança de TI
  - Cultura Organizacional
  - Segurança Cibernética

- **Metodologia BRIDGE**: Integração de RPA, DMN, AHP e Ergonomia Cognitiva
